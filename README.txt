Fahad Qaseem Khawar website (preview)

How to open:
1. Unzip / extract this folder first (don't open it from inside the zip).
2. Double-click index.html. It opens in your web browser.

Everything (photos, stickers, fonts) is built into index.html, so it works offline
on Windows and Mac. Use Chrome, Safari, Edge or Firefox.

Things to try:
- Click the camera's shutter to print photos, then drag the prints around.
- Steer the "Fahad Express" train: swipe/drag in its yard or use the arrow keys.
- Click any menu item and watch the stickers walk you there.
- Pick a leadership chapter, spin the Wayne State card, fly the plane on the route,
  swipe the project deck, and ask "Does Fahad know ___?" in the toolbox.
- Every sticker can be peeled off and moved (with a mouse).

To view it on a phone, put it online (for example, drag this folder onto
app.netlify.com/drop) and open that link on the phone.
